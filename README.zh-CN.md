# one-pager

一个把任何东西——一本书、六十页报告、会议纪要、一份提案——压缩成恰好一页 A4 纸的 Agent 技能：论证按亚马逊备忘录的标准来，排版像杂志美术桌的手艺。以标准技能目录打包（`npx skills add` 一键装），任何能读文件的编码 Agent 都能用。它**故意不是** PPT 工具。

[English](README.md) · **中文**

## 它做什么

它帮不以写作为生的人，产出站得住的一页纸——管理层备忘录、读书摘要、调研洞察——不需要你懂叙事结构，也不需要懂排版。方法是 **Show, don't tell**：不要求你用语言描述审美偏好，而是带着理由推荐一种长相，或者生成几版预览让你挑。

下面四页纸都是用这个技能做出来的——每张只展示首页，每页背后还附着一页证据：

每一页出厂前都过了技能自带的三十条断言。它产出的每一页都过同样的检查——包括那些让作者自己难堪的（见「评估与审计」）。

### 核心特性

- **一页，硬约束** —— 正文必须装进一页 A4。装不下就删字，永不缩字号。靠脚本验证，不靠祈祷。
- **两个决策层** —— 一套叙事方法论（亚马逊写作文化 × 麦肯锡咨询）加一套风格系统（四十八个亲手验过的样本），每层只有一份权威手册。内容和视觉从不越界吵架。
- **不懂风格术语也没关系** —— 说不清想要一页纸是什么「感觉」？很正常。它带着理由推荐，或问一个说人话的问题，或出三版预览让你用眼睛投票。
- **证据可以查** —— 正文里每个数字都带 `(D#)` 锚点，落进附页溯源表。任何一个数字，三分钟内查得到。（锚点这个东西，是技能自己的趣味所在。）
- **整本书也接** —— 输入五万字以上，交付分三层：一页纸（三十秒）+ 六页叙事稿（十分钟无声阅读）+ 不设上限的附页。中间那层借了亚马逊六页备忘录的规矩，包括「为没有人讲解的阅读而写」。
- **经得起第一次读** —— 破折号有预算、禁截图金句、行话首用自带白话注。润色时假设的读者，是个聪明但没见过你源材料的人。

## 安装

**任何支持技能的 Agent**（Claude Code、Codex、Cursor、Windsurf、iClaw、Baymax）：

```bash
npx skills add QinyuTan/one-page-doc-skills
```

**手动安装**：把 `one-pager/` 目录复制进你 Agent 的技能目录（如 `.claude/skills/` 或 `~/.agents/skills/`）。

**可选（导出 PDF 用）**：装 Python 和 `playwright`。不装也行，自带的 `export.py` 会回退系统 Edge/Chrome——慢一点，但能出活。要读 PDF 输入则需 `pypdf`（自带的 `extract.py` 用它）。除此之外什么都不需要：没有 npm，没有构建工具。

## 用法

### 把一本书读薄成一页

> 「帮我把《原则》的笔记读薄成一页纸，周五读书会用，重点讲团队能直接借鉴的」

1. 技能先路由场景（读者要*复述* → Book Memo 模式），动笔前就把判断说出来
2. 论证稿过九道质检门——电梯测试、So-What 扫描、模糊词猎杀——再做去 AI 味和首读者润色
3. 路由视觉（数据密集的摘要大概率被推荐瑞士蓝本），填满 A4 页
4. 查一遍不溢出，导出自包含 HTML 和 PDF

### 把实验结果变成决策页

> 「Q3 三个渠道压成一页给管理层，结论是砍信息流、预算转投裂变」

路由到*做决策*分叉 → Proposal 五段式：结论先行带决策旗标、观察因子、行动项落到具体 Owner。每个主张从你的数据里量化，每个数字锚定 `(D1)…(Dn)`。

### 压缩一份没人看的报告

> 「这份六十页调研报告发群里没人看，压成一页让人三分钟抓住核心」

路由到*被说服*分叉 → Insight Page 洞察页：结论块带置信度（技能会老实写「中等置信，四家样本，因果未验证」，而不是装没看见）、一图一结论、反方预案正面回应、模糊词零容忍。

连抱怨本身都能触发——「太长了，重点不突出」就是一份合格的简报。

### 它还能吃下这些

上面三个配方是骨架。真实的简报更杂——下面这些都是验证过能跑的，附上可以照抄的第一句话：

**有人要学点什么的时候**

| 你说 | 你得到 |
|---|---|
| 「把我们的团队规范 wiki 压成一页，下周一入职的新人要用」 | 一页团队文化的 Book Memo——能活下来的，才是真重要的 |
| 「这篇 20 页论文压成一页，重点讲方法和我能借鉴的实验设计」 | 组会不用开 PDF 就能复述的论文摘要 |
| 「把这周的课程笔记蒸馏成一页速查表，贴工位上」 | 去了行话的笔记——是贴墙的，不是归档的 |

**有人要拍板或行动的时候**

| 你说 | 你得到 |
|---|---|
| 「这周三条进展压成一页周报，老板只看三十秒」 | 三十秒会落在正确数字上的状态页 |
| 「我要向 VP 要两个外包名额，一页纸，数据在附件」 | 带决策旗标的提案——不是会被转发并附「看看？」的 deck |
| 「今天 40 分钟评审会的转写压成一页决策备忘录，谁拍板、谁做什么、什么时候」 | 会议纪要变成了决策，而不是变成了一个文件 |
| 「项目结了，把复盘文档压成一页」 | 下个 kickoff 前真能被读完的收尾备忘 |

**有人要被说服的时候**

| 你说 | 你得到 |
|---|---|
| 「这周 300 条用户投诉压成一页，按痛点和频次」 | 用频次而不是形容词说话的洞察页 |
| 「刚跑完的流失分析给运营一页，把反直觉的那条放最前面」 | 带置信度和反方预案的结论，不是等人解读的图表 |
| 「三家竞品的公开资料压成一页对比」 | 一个洞察、一张图——不是功能清单場 |

**换着方式喂它**

| 你说 | 你得到 |
|---|---|
| 「这份 45 页董事会 deck 压成一页，三个数字加一个诉求」 | deck 作*输入*接下（作*输出*拒绝——这条线就是这样） |
| 「压缩这个链接」（粘任意文章 URL） | 它抓取、路由、成页——链接即简报 |
| 「说服我 CEO 批准消息推送改版，这是我的初步想法」 | 0→1 模式：从你的想法出发逆向工作法建论证 |
| 「这本书」（一本 300 页 PDF 落进目录） | 批量模式自动启动：一页纸 + 六页叙事稿 + 证据附页 |

### 怎么驾驭它

- **说清读者是谁、读者要干什么。**「给管理层，周五拍板用」比「弄好一点」路由得准——三叉本身就是按读者下一步动作分的。
- **已有结论就直接给。**「结论是砍信息流」让它变成你的辩护人。不给结论它也照样论证——只是不会假装是数据替你做的决定。
- **风格随时可推翻。**它写 HTML 前先亮牌（分叉 + 模板 + 皮肤）——那就是你的窗口。「换成杂志特稿那种感觉」一句话的事。或者什么都不说，看它出的三版预览用眼睛挑。
- **发群要 PNG。**邮件和打印用 HTML，群聊和贴 PPT 用 PNG，附件用 PDF。
- **高风险场合记住附页。**溯源表是能在挑剔的 CFO 面前活下来的那部分：每个数字、哪里来的、怎么复核。

### 什么时候别用它

- 要的交付物是幻灯片 → 用幻灯片工具。这个技能会拒绝，有礼貌地，且是故意的。
- 需要完整保留原文档（合同、规格、审计记录）→ 压缩是错误操作；它向上归纳，不做向下归档。
- 要一个活的仪表盘 → 它做的是一次性的一页论证。刷新是另一码事。

## 内置风格

七套预捆模板，按用途分组。下面六张示例全部用同一份决策数据（一家书店的延时经营判断）做成，气质差异可以横向比着看。你永远不需要叫出它们的名字。

**决策与数据**

- [**瑞士蓝本**](examples/proposal-q3-budget-zh.png) —— 克莱因蓝 `#002FA7` 落在暖白纸上，发丝线分割，字号越大字重越轻。现代主义者的年报。
- [**档案账本**](examples/t3-ledger.html) —— 象牙纸配墨色，单一深点缀，账本行带档案编号。给白皮书和投资人简报——一切该活得比这个季度久的东西。

**故事与人**

- [**杂志特稿**](examples/t2-magazine.html) —— 衬线大标题、首字下沉、一个引文块、两栏对齐。周日刊的长篇特辑。
- [**纸上手作**](examples/t5-paper.html) —— 可读的无衬线正文上手写批注，纸纹、和纸胶带。手绘元素至多三处——再多就不 charming 了。

**宣言与态度**

- [**海报宣言**](examples/t4-poster.html) —— 半页超粗体给一句主张，另外半页装证据。奶油纸配消防红。
- [**时代复刻**](examples/t6-retro.html) —— 整页是一个 Win95 窗口：标题栏、菜单、状态栏、复选框。有意图的怀旧，不是戏服。
- [**终端黑幕**](examples/t7-terminal.html) —— 把决策渲染成一次 shell 会话：提示符、参数、语法高亮、`exit 0`。发给工程师的东西。

## 架构

**渐进式加载** —— 主 `SKILL.md` 是一张九十九行的工作流地图；支撑文件只在需要时才读。

| 文件 | 作用 | 何时加载 |
|---|---|---|
| `SKILL.md` | 四阶段管线编排 | 始终 |
| `references/narrative-methodology.md` | 亚马逊×麦肯锡叙事规则、三叉路由、九道质检门 | 阶段一（论证） |
| `references/humanize.md` | 去 AI 味清单 + 首读者可懂规则 | 阶段一（质检后） |
| `references/batch-mode.md` | 批量分级 N0/N1/N2 | 阶段一（输入 ≥ 5 万字） |
| `references/input-protocol.md` | 输入预检 + 验证工具箱 | 阶段零与阶段三 |
| `references/style-system.md` | 视觉路由、七套模板、十条硬规则 | 阶段二（排版） |
| `references/typography.md` | A4 机制、字号下限、`.page` DOM 契约 | 阶段二 |
| `assets/template.html` | 瑞士蓝本骨架：`.page` / `.narrative` / `.appendix` | 阶段二 |
| `scripts/` | `export.py` · `extract.py` · `check.py` | 阶段零与阶段三 |

## 哲学

1. **页面即论证。** 一页随时会溢出的纸，从来没被迫决定过什么才是重要的。
2. **九道门胜过好意图。** 写作变好，是因为有东西会把你打回去。
3. **证据住在附页。** 纪律住在正文。两者都要活过那场会议。
4. **平庸即遗忘。** 每页一种强调色，禁渐变，装饰不编码信息即删。
5. **没有锚点的数字是口号。** 每个数字都指向一个你能查的地方。

## 评估与审计

四个场景以全新子代理会话做了有技能/无技能对照：三叉路由四中四、结构断言全过、零模糊词、一页约束经两到三轮删词守住。零次缩字号——R1 是硬规则，验证器对作者本人也一样（它已经把这个技能自己的修改打回三次了）。

二十条触发路由模拟全对，包括幻灯片边界：幻灯片作*输入*（总结这份董事会材料）接下；幻灯片作*输出*（做二十页 PPT）拒绝。就是这么设计的。

三轮独立对抗审计：7.5 → 7.4 → 8.1。那次降分是真的——审计员抓到出厂示例没过自家新立的规矩，已重做，如今四份全部经 `scripts/check.py` 报 `ALL RUN CHECKS PASS`。老实说一句局限：审计只跑过一个模型家族，跨模型行为未验证——仓库克隆下来自带夹具和测试集，自己复跑一遍就知道了。
