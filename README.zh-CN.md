# one-pager

一个把任何东西——一本书、六十页报告、会议纪要、一份提案——压缩成恰好一页 A4 纸的 Agent 技能：论证按亚马逊备忘录的标准，排版像杂志美术桌的手艺。以标准技能目录打包（`npx skills add` 一键安装），任何能读文件的编码 Agent 都能用。它**故意不是** PPT 工具。

[English](README.md) · **中文**

## 它做什么

它帮不擅长写作的人，产出经得起审视的一页纸——管理层备忘录、读书摘要、调研洞察——不需要你懂叙事结构，也不需要懂排版。方法是**Show, don't tell**：不要求你用语言描述审美偏好，而是带着理由推荐一种长相，或者生成几版视觉预览让你挑喜欢的。

### 核心特性

- **一页硬约束** —— 正文必须装进一页 A4。装不下就删字，永不缩字号。靠脚本验证，不靠祈祷。
- **双决策层** —— 一套亚马逊×麦肯锡叙事方法论 + 一套四十八样本蒸馏的风格系统，每层只有一份权威手册。内容与视觉从不越界吵架。
- **视觉风格发现** —— 说不出自己想要什么风格？没关系。它带着理由推荐，或问一个说人话的问题，或出三版预览让你用眼睛投票。
- **证据可溯源** —— 正文里每个数字都带 `(D#)` 唯一锚点，落进附页溯源表。任何一个数字，三分钟内可完成复核。
- **整本书也接** —— 输入五万字以上，自动分级交付：一页纸（三十秒）+ 六页叙事稿（十分钟无声阅读）+ 不设上限的附页。
- **去 AI 味、首读者可懂** —— 破折号有预算、禁截图金句、句长有节奏、行话首用自带白话注。第一次读的人，一遍读得懂。

## 安装

**任何支持技能的 Agent**（Claude Code、Codex、Cursor、Windsurf、iClaw、Baymax）：

```bash
npx skills add QinyuTan/one-page-doc-skills
```

**手动安装**：把 `one-pager/` 目录复制进你 Agent 的技能目录（如 `.claude/skills/` 或 `~/.agents/skills/`）。

**可选（用于导出 PDF）**：装 Python 和 `playwright`——不装也行，自带的 `export.py` 会自动回退系统 Edge/Chrome。要读 PDF 输入则需 `pypdf`（自带的 `extract.py` 用它）。除此之外什么都不需要。没有 npm，没有构建工具。

## 用法

### 把一本书读薄成一页

> 「帮我把《原则》的笔记读薄成一页纸，周五读书会用，重点讲团队能直接借鉴的」

1. 技能先路由场景（读者要*复述* → Book Memo 读书备忘录模式），并在动笔前亮出路由结果
2. 论证稿过九道质检门（电梯测试、So-What 扫描、模糊词猎杀……），再做去 AI 味和首读者润色
3. 路由视觉——数据密集的摘要大概率推荐瑞士蓝本——填满 A4 页
4. 验证不溢出，导出自包含 HTML 和 PDF

### 把实验结果变成决策页

> 「Q3 三个渠道压成一页给管理层，结论是砍信息流、预算转投裂变」

1. 路由到*做决策*分叉 → Proposal 五段式（结论先行带决策旗标、观察因子、行动项带 Owner）
2. 从你的数据量化每个主张，每个数字锚定 `(D1)…(Dn)`
3. 路由视觉、成页、导出

### 压缩一份没人看的报告

> 「这份六十页调研报告发群里没人看，压成一页让人三分钟抓住核心」

路由到*被说服*分叉 → Insight Page 洞察页：结论块带置信度、一图一结论、反方预案正面回应、模糊词零容忍。

## 内置风格

七套预捆模板，按用途分组。每套都在风格系统里有完整规格——你永远不需要叫出它们的名字。

**决策与数据**

- **瑞士蓝本** —— 克莱因蓝 `#002FA7` 落在暖白纸上，发丝线分割，字号越大字重越轻。现代主义者的年报。
- **档案账本** —— 象牙纸配墨色，单一深点缀（腥红或深藏青），账本表格带档案编号。机构的地下档案库，适合白皮书与投资人简报。

**故事与人**

- **杂志特稿** —— 衬线大标题配无衬线正文，首字下沉，引文块，五套墨色主题。周日刊的长篇特辑。
- **纸上手作** —— 可读的无衬线正文上手写批注，纸纹、和纸胶带，手绘元素至多三处。工作坊的那张桌子。

**宣言与态度**

- **海报宣言** —— 半页超粗体给一句主张，另外半页装证据。黑底电光黄、奶油底消防红、深灰底橙，三选一。
- **时代复刻** —— Win95 窗口铬、卡带彩虹、riso 印刷，时代符号必须服务于叙事。有意图的怀旧。
- **终端黑幕** —— 终端绿 `#39d353` 落在 GitHub 暗色 `#0d1117` 上，全等宽字体，扫描线。发给工程师的东西。

## 架构

**渐进式加载** —— 主 `SKILL.md` 是一张九十九行的工作流地图；支撑文件只在需要时按需读取。

| 文件 | 作用 | 何时加载 |
|---|---|---|
| `SKILL.md` | 四阶段管线编排 | 始终 |
| `references/narrative-methodology.md` | 亚马逊×麦肯锡叙事规则、三叉路由、九道质检门 | 阶段一（论证） |
| `references/humanize.md` | 去 AI 味清单 + 首读者可懂规则 | 阶段一（质检后） |
| `references/batch-mode.md` | 批量分级 N0/N1/N2 | 阶段一（输入 ≥ 5 万字） |
| `references/input-protocol.md` | 输入预检 + 验证工具箱 | 阶段零与阶段三 |
| `references/style-system.md` | 视觉路由、七套模板、十条硬规则 | 阶段二（排版） |
| `references/typography.md` | A4 机制、字号下限、`.page` DOM 契约 | 阶段二 |
| `assets/template.html` | 瑞士蓝本骨架：`.page` / `.narrative` / `.appendix` | 阶段二 |
| `scripts/` | `export.py` · `extract.py` · `check.py` | 阶段零与阶段三 |

## 哲学

1. **约束本身，就是产品。** 一页随时会溢出的纸，从来没被迫决定过什么才是重要的。
2. **你不需要会写作，也能论证有力。** 你需要的是一扇把你打回去的门——这里有九扇。
3. **证据住在附页，纪律住在正文。**
4. **平庸即遗忘。** 每页一种强调色，禁渐变，装饰不编码信息即删。
5. **无法复核的主张是口号。** 每个数字都带锚点。

## 评估与审计

四个场景以全新子代理会话做了有技能/无技能对照：三叉路由四中四、结构断言全过、零模糊词、一页约束经两到三轮删词守住——从未缩过一个字号。二十条触发路由模拟全对，包括幻灯片边界：幻灯片作*输入*（总结这份董事会材料）接下；幻灯片作*输出*（做二十页 PPT）拒绝，这是立场。

这个技能经历过三轮独立对抗审计：7.5 → 7.4 → 8.1。那次降分是真的——审计员抓到出厂示例没过自家新立的规矩，已重做，如今经 `scripts/check.py` 全部报告 `ALL RUN CHECKS PASS`。测试集随仓库附输入夹具与复现协议，克隆下来一切可复跑。
