## 为什么需要它

每种常见格式都以同一种方式失败：幻灯片把一个观点拆成十二页要点；文档长过所有人的耐心；AI 摘要是一面没有层次的文字墙。

一页纸逼出最高形式的清晰——把所有真正重要的东西装进一页。**约束本身，就是产品。**

这个技能是两个决策层，每层只有一份权威手册：

| 层 | 管什么 | 蒸馏自哪里 |
|---|---|---|
| **叙事层** `narrative-methodology.md` | 说什么、怎么说、怎么删 | 亚马逊叙事文化（六页备忘录、PR/FAQ、逆向工作法）× 麦肯锡蒸馏术（金字塔原理、二八法则、结论式标题）——附完整来源谱系表 |
| **视觉层** `style-system.md` | 长什么样 | 四十八个一手风格样本 → 三层路由、七套预捆模板、十条硬规则、一份反 AI 味黑名单 |

外加不变的 A4 机制、双重文本润色、程序化验证工具箱。一层一个仲裁者，每一层都可审计。

## 三叉路由，只问一个问题

路由只问：*读者拿到这页纸，下一步做什么？*

| 读者动作 | 场景 | 房屋模式 |
|---|---|---|
| **复述它** | 书籍、课程、长文 | Book Memo 读书备忘录（阿德勒 × Sivers × 费曼） |
| **做决策** | 提案、审批、季度汇报 | Proposal 五段式（蒸馏自一份真实的 AWS GCR 提案） |
| **被说服** | 调研报告、数据分析 | Insight Page 洞察页（Zelazny × FT 数据新闻） |

输入是整本书（五万字以上）？批量模式自动分级交付：**N0** 一页纸（三十秒拿结论）+ **N1** 六页叙事稿（十分钟无声阅读，借鉴亚马逊六页备忘录原则）+ **N2** 不设上限的附页。读者按需下潜。

## 七种长相，零术语门槛

视觉层像美术指导一样路由——七种气质 × 七种骨架 × 五个皮肤槽，或者直接从货架上拿一套预捆模板：

| 预捆 | 名称 | 这一页像什么 |
|---|---|---|
| **T1** | 瑞士蓝本 | 一份由现代主义者排版的信托年报：克莱因蓝强调色、发丝线分割、字号越大字重越轻。适合数据汇报、决策文档、一切要打印给管理层的东西。 |
| **T2** | 杂志特稿 | 周日刊的长篇特辑：衬线大标题、首字下沉、引文块、五套墨色主题。适合故事、研究、一切与人有关的内容。 |
| **T3** | 档案账本 | 机构的地下档案库：象牙纸、墨色、单一深点缀色、带档案编号的账本表格。适合白皮书、投资人简报、一切应该显得「永不过时」的东西。 |
| **T4** | 海报宣言 | 半页纸给一句超粗体的主张，另外半页装证据。适合发布、宣言、必须一句话砸中人心的场合。 |
| **T5** | 纸上手作 | 手写批注、纸纹、和纸胶带——手绘元素至多三处。适合工作坊、访谈、一切需要温度的内容。 |
| **T6** | 时代复刻 | Win95 窗口铬、卡带彩虹、riso 印刷——时代符号必须服务于叙事。适合有意图的怀旧。 |
| **T7** | 终端黑幕 | GitHub 暗色画布、终端绿、全等宽字体、扫描线。适合开发者文档、一切发给工程师的东西。 |

**你不需要记住这些名字。** 风格发现协议只花最少的交互：

- 点名了风格（「瑞士风」「像杂志特稿」）→ 直接映射，偏差如实声明
- 措辞自带信号（「给领导看」「发布会」）→ 直接路由，不追问
- 场景明确 → **带理由推荐**（「数据汇报给管理层 → 瑞士蓝本：密度高、决策场景、打印友好」）
- 真拿不准 → **只问一个**问题，用参照物不用术语：*「这页纸更像哪种印刷品——董事会备忘录、杂志特稿、发布会海报，还是开发者文档？」*
- 还定不下来 → 出三版预览（稳妥 / 大胆 / 天马行空），用眼睛选

无论选了什么，它**在写下任何一行 HTML 之前就声明模板与皮肤参数**——十条硬规则一票否决一切模板脸：每页至多一种强调色、禁渐变、禁圆角、装饰不得无信息含义、中文大标题每行至多十二字。

## 管线

```
预检 → 论证 → 排版 → 导出
(输入分类     (三叉路由、    (风格路由、      (自包含 HTML
 PDF 提取、    三层协议、     填充页面、       + PDF/PNG
 整书扫描)     九道质检门、   验证不溢出)      + 六项程序化断言)
               文本润色)
```

正文里每个数字都带 `(D#)` 唯一锚点，与附页溯源表双向可查——读者对任何一个数字，三分钟内可完成复核。文本过双重润色：去 AI 味（破折号预算、禁截图金句、句长节奏变化）+ **首读者可懂**——每句话要活过第一次读它的人，行话首用自带白话注解。

## 安装

```bash
npx skills add QinyuTan/one-page-doc-skills
```

适配 Claude Code、Codex、Cursor、Windsurf、iClaw、Baymax——一切认技能的 Agent。**手动安装**：把 `one-pager/` 目录复制进你 Agent 的技能目录。**可选 Python**（用于导出）：`pip install playwright && playwright install chromium`（未装时自动回退系统 Edge/Chrome 无头模式）。

## 使用——说人话就行

- 「帮我把这本《原则》的笔记读薄成一页纸，周五读书会用」
- 「把 Q3 实验结果写成一页纸给管理层，结论是砍信息流投裂变」
- 「这份六十页调研报告发群里没人看，压成一页让人三分钟抓住核心」
- 「帮我们的种子轮写一页纸」

连抱怨本身都能触发：「太长了，重点不突出」就是一份合格的简报。技能在写任何 HTML 之前先亮牌——分叉、模板、皮肤——你随时可以推翻重选。

## 评估与审计

- **四个场景 ×（有技能 vs 无技能基线）** 子代理对照：三叉路由四中四、结构断言全过、零模糊词、一页约束经两到三轮删词回炉守住——**从未缩过一个字号**（R1 是硬规则）
- **触发路由二十中二十**模拟测试，含幻灯片边界用例：幻灯片作*输入*（总结这份董事会材料）→ 接；幻灯片作*输出*（做二十页 PPT）→ 拒绝，这是立场
- **三轮独立对抗审计**：7.5 → 7.4 → **8.1**。那次降分是真的——审计抓到四个示例没过自家新立的规矩，已重做并通过。四个内置示例经 `scripts/check.py` 全部报告 `ALL RUN CHECKS PASS`
- 测试集随仓库附输入夹具与复现协议——克隆下来，一切可复跑
