# one-pager 风格系统 · Style System v1.0

**目录**：0 决策流程 · 1 L1 气质层 · 2 L2 骨架层 · 3 L3 皮肤层 · 4 预捆模板 T1-T7 · 5 硬规则 R1-R10 · 6 反 AI slop 黑名单 · 7 密度双模式（含信息组定义）· 8 快速路由表

> **角色**：你是 one-pager skill 的视觉决策层。叙事内容（说什么）由叙事模板负责；视觉风格（长什么样）完全由本文件裁决。生成任何 HTML 一页纸之前，必须先完成 L1→L2→L3 三次选择，在输出开头声明「模板编号 + 皮肤参数」，然后才允许写代码。
>
> **术语消歧（编者注）**：本文件的 L1/L2/L3 指视觉三层（气质/骨架/皮肤）；narrative-methodology.md 中的 L1/L2/L3 指叙事三层（论证/段落/句子）。两套编号互不相干，读哪份文件就以哪份为准。
>
> **来源**：48 个一手风格样本蒸馏——guizang-ppt-skill（电子杂志 × 瑞士国际主义 2 套深度系统）× frontend-slides（12 安全预设 + 34 bold 模板）。
>
> **组织原则**：
> - **MECE**：层内选项互斥（一个输入只路由到一个选项）、层间正交（气质管情绪、骨架管结构、皮肤管参数）、合并穷尽（任意风格诉求都能落位）。气质层的三轴为 温度（冷↔暖）× 能量（静↔响）× 时代（过去↔当下↔未来）；风格词跨界时取主导轴，裁决标准是"读者第一眼感到什么"。
> - **3-7 原则**：决策树 ≤3 层深；每个决策节点 3-7 个选项（7±2 认知负荷上限）；配色面积遵守 70/30/10 三七开（见 R2）。

## 0 · 决策流程

```
用户措辞 / 内容主题
   ↓ 情绪路由（第 8 节速查表）
L1 气质 —— 7 选 1
   ↓ 按内容形状匹配（不是按喜好）
L2 骨架 —— 7 选 1
   ↓ 参数微调
L3 皮肤 —— 5 个参数槽，每槽 3-7 选 1
   ↓
硬规则 R1-R10 全检 →（拿不准审美时）出 3 预览让用户眼选 → 写 HTML
```

两条捷径：
- **不确定时直接取预捆模板**（第 4 节 T1-T7），再按需改皮肤参数。
- **用户显式点名风格**（如"我要瑞士风""像杂志特稿"）→ 直接映射到最近模板，映射不到 100% 时在声明中说明偏差后继续，不反复追问。

## 1 · L1 气质层（情绪，7 选 1）

定义：页面给读者的第一情绪印象。

| # | 气质 | 路由关键词 | 定位 |
|---|---|---|---|
| C1 | 严谨理性 | 专业、数据、汇报、系统、网格、咨询、工程 | 冷 / 中 / 当下 |
| C2 | 人文温度 | 故事、杂志、叙事、深度、观察、文学、人文 | 暖 / 中 / 当下 |
| C3 | 克制高级 | 高级、学术、白皮书、档案、沉静、投资、机构 | 冷 / 静 / 当下 |
| C4 | 大胆宣言 | 发布、主张、宣言、冲击、年轻、品牌、金句 | 暖 / 响 / 当下 |
| C5 | 温暖手作 | 手工、纸感、访谈、质性、共创、工作坊 | 暖 / 静 / 当下 |
| C6 | 复古怀旧 | 怀旧、90 年代、印刷、zine、卡带、老物件 | 暖 / 中 / 过去 |
| C7 | 科技未来 | 极客、终端、赛博、霓虹、开发者、AI 原生 | 冷 / 响 / 未来 |

互斥裁决：同时命中多桶时，问"读者第一眼感到什么"，取主导印象，不折中混搭。

## 2 · L2 骨架层（结构，7 选 1）

定义：承载 A4 单页信息的主导结构装置。**按内容形状选，不按审美偏好选。**

| # | 骨架 | 结构装置 | 适用内容形状 |
|---|---|---|---|
| S1 | 网格系统 | 12 列网格 + hairline 分割 + 非对称留白 | 多模块并列、层级清晰 |
| S2 | 编辑排版 | 2-3 栏正文流 + 衬线大标题 + 图注 / pull quote | 长文叙事、图文并茂 |
| S3 | 账本档案 | 横线表格 + 规则线 + 等宽元数据 + 编号 | 条目化、数据行、研究资料 |
| S4 | 海报构图 | 上 1/2 超大字单一视觉锤 + 下 1/2 信息区 | 一句主张 + 少量支撑 |
| S5 | 纵向分屏 | 左右或上下两区（文/图、问题/方案） | 二元对照、图文各半 |
| S6 | 模块卡片 | 2×2 / 3×2 等权信息块 | 并列概念、清单、checklist |
| S7 | 数据叙事 | KPI 大字做 hero + 图表为主体 | 指标汇报、量化结论 |

骨架-内容匹配铁律：数据没有真实数值不得用 S7；主张提炼不出一句话不得用 S4；正文不足 300 字不得用 S2；只有两组对照优先 S5 而非 S6。

## 3 · L3 皮肤层（参数，5 槽）

| 槽 | 选项（每槽选 1） | 缺省 |
|---|---|---|
| 明度 | 亮底 / 暗底 / 分区混合（上下或左右异底） | 亮底 |
| 色彩策略 | 无彩 / 单 accent / 双色 / 三色系统 / 多彩点缀 | 单 accent |
| 字体搭配 | ① 衬线 display + 无衬线正文 ② 全无衬线 ③ 等宽 + 无衬线 ④ 全衬线 ⑤ 超粗 display + 无衬线 ⑥ 手写体 + 无衬线 ⑦ 时代特征字 + 无衬线 | 随气质 |
| 形状语言 | 直角 / 小圆角 / 手绘不规则 | 直角 |
| 装饰密度 | 零装饰 / 单一装饰语言 / 纹理 + 点缀 / 多层装饰 | 单一 |

字体搭配槽 ①-⑦ 与气质的推荐对应：①→C2/C3、②→C1、③→C7、④→C3、⑤→C4、⑥→C5、⑦→C6。

## 4 · 预捆模板 T1-T7（开箱即用）

### T1 瑞士蓝本（C1 严谨理性）

| 项 | 值 |
|---|---|
| 骨架 / 皮肤 | S1 网格 · 亮底 · 单 accent · 全无衬线 · 直角 · 点阵（仅 hero 区） |
| 字体 | display：Space Grotesk / Archivo 级 + Noto Sans SC；meta：等宽大写 + letter-spacing |
| accent（四选一，禁自定义 hex） | IKB 克莱因蓝 `#002FA7` / 柠檬黄 `#FFD500` / 柠檬绿 `#C5E803` / 安全橙 `#FF6B35` |
| 签名装饰 | 1px hairline 分割 + 8px 直角小方块 |
| 字重阶梯 | 越大越细：display ≤300、正文 300-400、小标注 500-600；display:正文 ≥4:1 |
| 专属禁令 | 渐变 / 阴影 / 圆角 / 第二 accent / 任何衬线字体 |
| 溯源 | guizang Style B × Swiss Modern × Neo-Grid Bold |

### T2 杂志特稿（C2 人文温度）

| 项 | 值 |
|---|---|
| 骨架 / 皮肤 | S2 编辑排版 · 亮底 · 三色系统 · 衬线 + 无衬线 · 直角 · 低装饰 |
| 字体 | display：Noto Serif SC + Playfair Display 级；正文无衬线；meta 等宽 |
| 主题（五选一，禁自定义） | 墨水经典 / 靛蓝瓷 / 森林墨 / 牛皮纸 / 沙丘 |
| 签名装饰 | 首字下沉 或 pull quote；图片是第一公民（裁切保主体、必有图注） |
| 专属禁令 | 阴影 / 浮动卡片 / padding box 堆叠；信息层级靠字号与字体对比 |
| 溯源 | guizang Style A × Vintage Editorial × Editorial Forest |

### T3 档案账本（C3 克制高级）

| 项 | 值 |
|---|---|
| 骨架 / 皮肤 | S3 账本档案 · 亮底 · 无彩 + 1 个深点缀色 · 衬线 + 等宽 · 直角 · 零装饰 |

| 签名装饰 | 横线表格 + 档案编号 + 页眉规则线 |

### T4 海报宣言（C4 大胆宣言）

| 项 | 值 |
|---|---|
| 骨架 / 皮肤 | S4 海报构图 · 亮或暗 · 单饱和 accent · 超粗 display · 直角 · 单一装饰 |
| 字体 | display：Archivo Black / Shrikhand 级（中文用超黑）；正文无衬线 |

### T5 纸上手作（C5 温暖手作）

| 项 | 值 |

## 5 · 硬规则 R1-R10（任何模板都必须过，一票否决）

- **R1 一页约束**：A4 画布（210×297mm），生成后用 scrollHeight 断言不溢出。放不下先删内容或换骨架，**禁止缩字号硬塞**。
- **R2 三七面积律**：底色 ≈70%、次级色 ≈30%、accent ≤10%。单 accent 全页至多一处大面积或三处小面积。
- **R3 字号对比与下限**：display:正文 ≥4:1（S4 海报型 ≥8:1）。A4 中文：正文 9.5-10.5pt、meta 8pt、最小 7.5pt，低于下限先删字。
- **R4 字重阶梯**：无衬线体系"越大越细"（display ≤300、小标注 ≥500）；衬线体系遵循传统配比，不受此条约束。
- **R5 字体三级分工**：display / 正文 / meta（等宽）三职必须由三种不同字体角色承担，不许一种字体包打天下。
- **R6 装饰预算**：全页至多 2 种装饰语言；同一信息组内装饰必须统一。
- **R7 图文关系**：图片裁切保主体；必有图注；只用标准比例（16:10 / 4:3 / 3:2 / 1:1）；同组图片比例统一。
- **R8 密度双模式**：读薄型 ≤3 个信息组、留白 ≥40%；汇报型 ≤5 个信息组、网格自足。两种模式都不许溢出画布。
- **R9 中文优先**：字体栈必须带 CJK 兜底（`"Noto Sans SC","Microsoft YaHei UI"`）；中文大标题 1 行 ≤12 字，超出先改文案再降字号。
- **R10 Show Don't Tell**：用户审美不明时，出 3 个预览（对应气质的安全模板 ×1 + 大胆变体 ×1 + wildcard 自由设计 ×1），让用户用眼睛选。预览页面禁止出现 "preview / Option A / 草稿" 等流程元信息。

## 6 · 反 AI slop 黑名单（负空间，一票否决）

- **字体**：Inter / Roboto / Arial / 系统字体做 display；同一用户连续两次用 Space Grotesk（防收敛）。
- **颜色**：`#6366f1` 通用靛蓝；白底紫渐变。
- **布局**：整页居中；通用 hero 区；一模一样毫无主次的卡片阵列。
- **装饰**：写实插画；无目的 glassmorphism；无意义阴影与圆角堆叠。
- **图标**：emoji 充当图标（用 Lucide 等图标库）。

## 7 · 密度双模式（与叙事模板对齐）

**信息组定义（编者注）**：信息组 = 页面上的顶层视觉分组，即一个分节装置（如 sec-label 或等价物）统领的整个区域——标题、正文、图表、表格合计为一组。房屋模式的"段"是叙事段落，不是信息组：Book Memo 七段骨架典型落在 3 个信息组内（头部定位区 / 主体区 / 行动收束区），Proposal 五段式落在 ≤5 组。数信息组时看页面分节，不看叙事段落数。

| 叙事模板 | 密度模式 | 视觉行为 |
|---|---|---|
| 学习读薄型 | 低密度 | ≤3 信息组、display 拉大、留白 ≥40%、每组一个视觉锚点 |
| 说服汇报型 | 中高密度 | ≤5 信息组、网格承载、结构自足（离开讲解也能读懂）、结论前置 |

共享底线：无滚动、无溢出、无重叠面板、字号不低于 R3 下限。内容超限拆附页或删减，不压缩排版。
